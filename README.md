# Rocks Automation

## Installation
1. Clone repo fullscale-rocks-test-automation
2. execute command in terminal `npm install`. Make sure you are in the root directory of the repo

## Running Playwright
Refer to link [Running Playwright](https://playwright.dev/docs/running-tests)
### Run all tests
Execute `npx playwright test`
### UI Mode
Execute `npx playwright test --ui`
### Headed Mode
Execute `npx playwright test --headed`
### Run specific test
Execute `npx playwright test <path and filename of the test>`
